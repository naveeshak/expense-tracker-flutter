# Expense Tracker 

A simple and clean expense tracking mobile application built with Flutter and Firebase.

## Features

- Add expenses
- Edit expenses
- Delete expenses
- Select expense categories
- Store data using Firebase Firestore
- View monthly total expenses
- Filter expenses by category and month
- Search expenses
- Category-wise expense summary
- Pie chart for category expenses
- Dark mode
- Form validation
- Loading, empty, and error states

## Expense Details

Each expense includes:

- Title
- Amount
- Category
- Date
- Optional note

## Technologies Used

- Flutter
- Dart
- Firebase Core
- Cloud Firestore
- FL Chart

## Project Setup

1. Clone the repository.
2. Run: `flutter pub get`
3. Connect the project to Firebase.
4. Add the required `google-services.json` file inside: `android/app/`
5. Run the app: `flutter run`
